# Northlane QR

Privacy-first QR code generator. Static, dependency-free app that runs entirely in the browser.

## Deploy

Import this folder into GitHub, then import the repository in Vercel. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.

## Features

- URL, text, Wi-Fi, WhatsApp and email QR formats
- Local generation; no backend or uploaded data
- PNG download and copy action
- Responsive SEO landing page
